STARSHIP V3 EXPLORER · V3

Modelo didáctico a escala visual aproximada 1:1. Explora el exterior, activa el corte y observa los sistemas principales. La geometría interna es esquemática, no un plano de fabricación. V4: inspección y manipulación VR experimental.

Arrastra para girar · rueda/pellizco para acercar · entra en VR con el botón inferior.
Meta Quest 3: abre este proyecto desde un sitio HTTPS y pulsa “ENTER VR”.
En VR: activa INSPECCIÓN, pellizca para agarrar y desplazar piezas, gira la muñeca para rotarlas y suelta para dejarlas. Apunta con el mando y pulsa el gatillo para seleccionar. Los paneles flotantes permiten cambiar modos.
